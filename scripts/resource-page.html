GAPLink

GAPLink connects Wolfram Language to GAP.

Install

PacletInstall[
    "https://www.wolframcloud.com/obj/wolframinstitute/GAPLink/" <>
        "WolframInstitute__GAPLink-" <> $SystemID <> ".paclet"
];

Release paclets include a tested GAP runtime.

Quick test

Needs["WolframInstitute`GAPLink`"];

session = StartGAPSession[];
GAPCall[session, "Size", GAPCall[session, "SymmetricGroup", 4]]
DeleteObject[session];

The result is 24.
